# Бура Онлайн 🃏

Простая онлайн-версия карточной игры «Бура» на 3-4 игроков. Реалтайм через Socket.io.

## Структура
- `server/` — бэкенд (Node.js + Socket.io) → деплоится на **Railway**
- `client/` — фронтенд (чистый HTML/CSS/JS, без сборки) → деплоится на **Vercel**

## Деплой (с телефона, через браузер)

### 1. Railway (бэкенд)
1. Зайди на railway.app → **New Project** → **Deploy from GitHub repo**
2. Выбери репозиторий `Bura_online`
3. В настройках проекта (Settings) укажи **Root Directory**: `server`
4. Railway сам определит Node.js и запустит `npm start`
5. После деплоя зайди в **Settings → Networking → Generate Domain** — получишь публичный URL вида `https://xxxx.up.railway.app`

### 2. Vercel (фронтенд)
1. Зайди на vercel.com → **Add New Project** → **Import Git Repository**
2. Выбери репозиторий `Bura_online`
3. В настройках проекта укажи **Root Directory**: `client`
4. Framework Preset — **Other** (это статичный сайт, сборка не нужна)
5. Deploy

### 3. Игра
1. Открой сайт на Vercel
2. В поле «Адрес сервера» вставь URL с Railway (из шага 1.5)
3. Введи имя → «Создать новую комнату»
4. Скинь код комнаты друзьям — они вводят тот же URL сервера + код и жмут «Войти»
5. Хост жмёт «Начать игру», когда набралось 3-4 игрока

## Правила (кратко)
- Колода 36 карт (6…Туз), козырь определяется случайной картой при раздаче
- Каждому по 3 карты, после взятки — добор из колоды
- Побеждает тот, кто первым наберёт 31+ очко за раздачу, либо у кого больше очков, когда колода и карты закончились
- Очки: 6-9 = 0, 10 = 10, В = 2, Д = 3, К = 4, Т = 11
